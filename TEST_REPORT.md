# Проверка сборки

Дата: 11 сентября 2026 года.

**31 тест пройден.** Среда: Windows, Python 3.13, зависимости из `requirements.lock.txt`.

Проверены:

- Проход через обработчики aiogram: старт, каталог, карточка, корзина, доставка, контакты, адрес, подтверждение, история и уведомления. Telegram API заменён тестовым транспортом.
- Одновременное повторное подтверждение: один заказ и один набор уведомлений.
- Изменение цены, наличия, корзины, условий и закрытие магазина до подтверждения.
- Минимальная сумма, бесплатная доставка, границы количества и точность денежных сумм.
- Сохранение первоначальных цен в истории и допустимые переходы статусов.
- Блокировка получателем, ограничение Telegram по частоте и повторные попытки уведомлений.
- Вход в веб-панель, ограничение попыток, обязательный CSRF, аннулирование сессии при смене пароля.
- Создание товара, загрузка изображения, отбрасывание поддельного и слишком большого файла, экранирование HTML.
- Отображение всех основных страниц и сохранение настроек.
- Интерактивная настройка `.env`, хранение пароля только в хеше.
- Согласованное резервное копирование SQLite и чтение восстановленной базы.

В браузере визуально проверены панель и форма товара, в том числе чёрно-красная тема «Осень Кусна» на узкой ширине окна. Демонстрация доступна локально на компьютере, где создавался проект.

Тестовый клиент выдаёт два предупреждения об устаревающих интерфейсах httpx/AnyIO внутри Starlette. Ошибок тестов нет.

Не проводились: реальная отправка в Telegram без токена владельца; установка systemd/Nginx на настоящий VPS; работа на кассе iiko. Для них нужны соответствующие доступы. В сборке отсутствует активная интеграция iiko.

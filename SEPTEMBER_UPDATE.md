# Обновление от 27 сентября 2026 года

## Что изменилось

Импорт iiko больше не исключает блюдо только из-за canBeDivided: сайт заказывает целые порции. Необязательные модификаторы можно опустить, только когда ограничения группы и дочерних модификаторов явно допускают ноль и не задают выбранные по умолчанию добавки. Обязательные/неизвестные ограничения и составные блюда по-прежнему не обходятся. UUID организации в ценах сравниваются без учёта регистра. При пустом результате предпросмотр показывает причины пропуска и не предлагает применить пустое меню.

Скриншоты iikoWeb подтверждают наличие цены в интерфейсе, но не показывают JSON ответа Cloud API. Успешный импорт конкретного меню ресторана ещё нужно проверить на VPS. Если проблема сохранится: Интеграции → iiko → «Скачать диагностику меню без ключей». Отчёт содержит выбранные ID, счётчики и допустимые поля первых 30 блюд; ключи, токены и заказы не включаются. Его можно передать разработчику. Не отправляйте .env или полный ответ авторизации.

Корзина поддерживает скидку на самовывоз, выбор четырёх районов доставки и наличную/карточную оплату при получении. Онлайн-оплата остаётся доступной только при настроенном эквайринге. СБП выбирается в форме банка при доступности на терминале. За пределами районов заказ оформляется по телефону после согласования стоимости; неизвестная доставка не выдаётся за бесплатную. Выбор района не является геокодированием: соответствие адреса проверяет сотрудник до принятия заказа.

Скидка применяется к каждой единице товара с округлением итоговой цены до копейки. У заказа сохраняются скидка и фактические цены; эти же цены используются в чеке Т-Банка и передаче iiko. Для web- и Telegram-заказов сохраняется снимок условий. Старые заказы не пересчитываются.

## Обновить существующий VPS

Выполняйте по очереди, при ошибке остановитесь. Сначала дождитесь завершения текущих заказов/оплат и сохраните резервную копию вне VPS. Сайт временно недоступен, пока сервисы остановлены.

```bash
cd /opt/sushi-bot
git status --short
git fetch origin
git rev-parse HEAD
sudo systemctl stop sushi-web sushi-bot
sudo -u sushi .venv/bin/python -m app.manage backup
sudo install -m 600 .env "/root/sushi-env-$(date +%Y%m%d-%H%M%S).bak"
git switch feature/online-store
git merge --ff-only origin/feature/online-store
.venv/bin/python -m pip install -r requirements.lock.txt
sudo -u sushi .venv/bin/python -m app.manage init
sudo -u sushi .venv/bin/python -m app.manage shop-profile
sudo systemctl restart sushi-web sushi-bot
sudo systemctl status sushi-web sushi-bot --no-pager -l
curl --fail http://127.0.0.1:8000/health
```

Если `git status` показывает изменённые файлы, сначала сохраните и разберите эти изменения. Не используйте `reset --hard`. `shop-profile` — явное однократное применение согласованных условий, а не обязательная часть каждого обновления. Оно заменяет телефон, часы, адрес самовывоза, основные реквизиты, тарифы, минимальный заказ (0), скидку (10% на всё меню), районы и возможность оплаты картой при получении. Не запускайте повторно после самостоятельного редактирования этих полей. Ключи, каталог, документы, email и адрес для обращений не изменяются; интеграции и приём заказов не включаются.

Главная: https://app.osenkusna.ru/ . Админка: https://app.osenkusna.ru/admin . Домен и сертификат менять не требуется. После обновления обновите страницу Ctrl+F5.

## Документы и готовность к продажам

В подвале размещены контакты и реквизиты, доставка и оплата, оферта, отмена/возврат и политика конфиденциальности. Если поля текстов документов в «Оформлении» пустые, используются новые встроенные тексты с текущими тарифами. Уже заполненные собственные документы сохраняются и требуют ручной сверки.

Предоставленный DOCX относится к «Суши Вок»: в нём чужие реквизиты, личный кабинет с SMS и другие функции, отсутствующие в этом магазине. Эти положения не перенесены. Вместо копирования подготовлен отдельный проект под текущий процесс заказа.

Получены от владельца: ИП Абкеев Искандер, ИНН 165510330630, ОГРНИП 324169000163148. Достоверность сведений по ЕГРИП отдельно не проверялась. Email и адрес для юридически значимых обращений не предоставлены; отчество не добавлено. В админке показано напоминание, в документах незаполненные сведения явно отмечены. Перед публичными продажами заполните их и сверьте полное имя и сведения о регистрации с ЕГРИП. Адрес самовывоза не подставляется вместо адреса ИП.

Основание обработки минимальных данных для заказа — заключение и исполнение договора (п. 5 ч. 1 ст. 6 № 152-ФЗ). В форме осталась галочка принятия оферты и отдельная ссылка на политику, без объединённого «согласия на всё» и рекламной подписки. Если оператор добавит иные цели/поручения, требующие согласия, нужны самостоятельные основание и документ. Это не универсальный аудит соответствия бизнеса всем законам РФ.

До публичных продаж владелец проверяет фактические процессы: кассу и чеки (включая закрывающий чек и возврат), размещение баз данных и резервных копий в РФ, уведомления Роскомнадзору при необходимости, договоры/основания передачи хостингу, iiko, курьерам и Telegram, права доступа, сроки хранения и выполнение запросов на удаление. Автоматического удаления старых заказов в этой версии нет; политику хранения необходимо определить и обеспечить организационно/технически. Уведомления Telegram могут содержать данные заказа; использование внешнего сервиса отдельно оценивается оператором.

Заполните состав, аллергены, вес, пищевую ценность, срок годности и хранение по реальным технологическим картам. Для последних трёх сведений добавлены поля карточки; нулевые БЖУ со скриншота не выданы за подтверждённые значения. Импортированное описание iiko по-прежнему не считается автоматически проверенным составом.

# Что заполнить в .env

`.env` — локальный текстовый файл настроек и секретов. Бот и веб-панель читают его при запуске. В репозитории хранится только `.env.example` с пустыми секретами.

Проще всего выполнить `python -m app.manage setup` в установленном виртуальном окружении. На Windows это автоматически предлагает `START-WINDOWS.cmd`. Настройка запросит токен, Telegram ID, логин и пароль; хеш пароля и секрет сессии создаст сама.

| Переменная | Что это | Что указать |
|---|---|---|
| `BOT_TOKEN` | Доступ к Telegram Bot API | Токен вашего бота от @BotFather |
| `ADMIN_IDS` | Кому отправлять новые заказы в Telegram | Числовой ID от @userinfobot; несколько ID через запятую |
| `ADMIN_USERNAME` | Логин веб-админки | Можно оставить `admin` или написать свой |
| `ADMIN_PASSWORD_HASH` | Хеш пароля веб-админки | Создаётся через `setup` или `python -m app.manage password`; обычный пароль сюда не вставляют |
| `SESSION_SECRET` | Секрет, которым сервер подписывает сессии входа | Генерируется через `setup` или `python -m app.manage secret`, минимум 32 символа |
| `COOKIE_SECURE` | Передавать cookie входа только по HTTPS | `false` при локальной проверке и SSH-туннеле; `true` на домене с HTTPS |
| `PUBLIC_URL` | Домен магазина для мини-приложения Telegram по умолчанию | Например, `https://app.osenkusna.ru`; можно указать в админке вместо `.env` |
| `MAX_CA_BUNDLE` | Дополнительные доверенные корневые сертификаты для запросов к MAX | Необязательный абсолютный путь к PEM; настройка описана в MESSENGERS.md |
| `DATA_DIR` | Папка базы данных, фото и резервных копий | Локально `./data`, на VPS можно `/opt/sushi-bot/data` |
| `SHOP_NAME` | Первоначальное название магазина | `Осень Кусна` |
| `CURRENCY` | Первоначальное обозначение валюты | `₽` или другое обозначение |

Помимо токена, обязательно нужны непустые `ADMIN_IDS`, `ADMIN_PASSWORD_HASH`, `SESSION_SECRET`. `ADMIN_USERNAME` имеет значение по умолчанию. `ADMIN_IDS` не является паролем веб-панели и не ограничивает круг покупателей: он определяет получателей уведомлений.

Каждый администратор должен первым отправить боту `/start`, иначе Telegram не разрешит отправить ему уведомление.

`SHOP_NAME` и `CURRENCY` используются только при первоначальном заполнении настроек базы. После первого запуска меняйте их в веб-админке → **Настройки**. Там же задаются адрес, телефон, часы, доставка и приём заказов. Отдельных переменных `.env` для этих полей нет.

После изменений `.env` перезапустите бота и веб-панель. На VPS: `sudo systemctl restart sushi-bot sushi-web`. В локальном запуске: Ctrl+C, затем снова `START-WINDOWS.cmd`.

Файл `.env` не должен попадать в GitHub, архивы с кодом или публичные сообщения. Он уже исключён через `.gitignore`. Хеш пароля тоже не публикуйте. Рабочая база, фотографии и бэкапы хранятся в `data/`, которая также исключена из Git.

Для iiko переменных `.env` нет: обмен и импорт меню настраиваются в разделе «Подключения» веб-админки.

## Сайт заказов и интеграции

Telegram Mini App и MAX: [MESSENGERS.md](MESSENGERS.md). Токен MAX сохраняется только в зашифрованных настройках админки. Пока токена нет, оставьте MAX выключенным. Для мини-приложений на VPS обязательно `COOKIE_SECURE=true`.

Т-Банк и iiko настраиваются в `/admin/integrations`, а оформление — в `/admin/appearance`. Дополнительных переменных `.env` для них не требуется. Telegram использует `.env`, пока не задано переопределение в админке. `SESSION_SECRET` не является ключом шифрования интеграций: он создаётся отдельно в `DATA_DIR/integrations.key`. Сохраняйте базу и этот файл вместе в защищённой резервной копии. Детали обновления: [STORE_LAUNCH.md](STORE_LAUNCH.md).
